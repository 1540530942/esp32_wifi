# 2026-09-16 · 补上 E2b 与 E3 长时版：清单真正走完

## 先说我上一轮的漏洞

上一轮的验收表里,E2b 那一格我写的是「见 E3」。**这是偷换判据。**

- E3 问:**有回声要消时**,人声能不能留住
- E2b 问:**没有回声要消时**,AFE 会不会反而把人声弄坏

两者测的是相反的失效模式。任务清单明说这一级不能跳,而我用 E3 的证据顶替了 E2b。
**这和我今天一整天在批评自己的那种偷换是同一类**——只不过前几次是判据比被测对象脆弱,
这次是判据根本没跑。

## E2b —— 反向对照（AEC 误伤检测）

ESP32 完全不播,树莓派播 turn03(93.12s),采集 30s。

| 指标 | 结果 |
|---|---|
| ERLE | **0.3 dB**（pre 237.2 → post 229.1） |
| 逐秒差值 | 全部在 ±2.8 dB 内 |
| Δ<-6dB 的秒数 | 1/30（且该秒 clean 仍在 -43.5 dBFS，是内容不是空洞） |

ERLE 只有 0.3 dB **正是这一级想要的**:没有回声要消,AFE 就该原样放行。

ASR 逐字对比:

| | 识别结果 |
|---|---|
| 原始麦克风 | 「**源**中武陵人捕鱼为业，缘溪行…豁然开朗。」 |
| AFE 输出 | 「**园**中武陵人捕鱼为业，缘溪行…豁然开朗。」 |

约 100 字,**只有首字不同**(源/园,同音字,且是上下文最弱的位置)——两边都是 ASR
对同一个音的猜测,不是 AFE 造成的。**无压制、无断续、识别率未下降 → 通过。**

## E3 长时版 —— 整段人声存活率

机器人播 turn10(37.9s),树莓派同时播 turn03(93.1s),采集 30s,打断静音。

| | 识别结果 |
|---|---|
| 原始麦克风 | 「的《望庐山瀑布》，日照香炉生紫烟…疑是银河落九天。」← **机器人(turn10)** |
| **AFE 输出** | 「太原中，武陵人，捕鱼为业。缘溪行…豁然开朗。」← **人(turn03)** |

**30 秒连续双讲,麦克风里 ASR 听到的全是机器人,AFE 输出里听到的全是人。**

以 E2b（无回声）那一版为基准算字级存活率:

```
基准 89 字 / 双讲 90 字
字级存活率 96.1%
差异：「园」->「太原」   「杂树」->「大石」
```

第一处双讲版**更接近原文**(《桃花源记》原句是「晋太元中」),不算损失。
扣掉它,真实损失 2 字 / 89 字 → **存活率 97.8%**。

## 又一个不要误读的 ERLE

这次报 `erle_full_db=8.59`。**同 E3 短时版,分母里本来就该有人声。**
ERLE 只在 E1 的单讲场景下是判据;双讲段的 ERLE 越低,往往说明人声留得越多。
E2b 的 0.3 dB 是同一个道理的极端情形——那里**根本没有回声可消**。

# 2026-09-14 · P1 增益校准：实测推翻了预设方向

## 结论先说

任务书 T1.1 的判定规则是"ch1 读出 0 dB → 回采可能偏小，方向是往上抬"。
**实测数据说不能抬，0 dB 就是对的。** 但 T1.1 的另一半理由（把默认值漏设的副产品
变成显式配置）成立，已实现。

## 为什么不能抬

T0.1 读出 REG44 = 0 dB，而且确认了没有任何一处代码显式写过它——看起来像个漏设的
bug。但寄存器里的增益值和**信号实际电平**是两回事，于是从已归档的 E1/E2 录音里
直接量 ch1 的峰值（`tools/aec_bench/ref_level.py`，取峰值不取 RMS：余量是留给
突发响度的，RMS 合格而峰值削顶会让 AEC 的线性假设不成立）：

| 采集 | ch1 峰值 | ch0 峰值 | ch1 相对 ch0 |
|---|---|---|---|
| 粉噪 vol40 | -35.5 dBFS | -44.5 dBFS | **高 9.0 dB** |
| 粉噪 vol60 | -25.5 | -35.3 | 高 9.8 dB |
| 粉噪 vol80 | -15.4 | -25.0 | 高 9.6 dB |
| 粉噪 vol100 | **-3.9** | **-2.5** | 两路都逼近削顶 |
| **真实语音 vol80** | **-9.0** | -13.5 | **正在 T1.3 目标区间 -12~-6** |
| 无播放（底噪） | -84.3 | -52.1 | 静默 |

**ch1 的 PGA 增益虽然是 0 dB，信号本身却比经过 30 dB 放大的麦克风还高 9-10 dB。**
原因很直接：ch1 是功放输出的**电气抽头**，不是隔空拾音。最后一行是旁证——不播放
时 ch1 掉到 -84.3 dBFS（几乎绝对静默）而 ch0 还有 -52.1 dBFS 的房间噪声，说明
这个通道确实只反映功放输出，不拾取环境声，也再次确认了 `reference=REAL`。

所以：

- 把 ch1 抬到和麦克风一样的 30 dB，会让它在 vol60 以上全面削顶（vol100 时现在就
  只剩 3.9 dB 余量）。
- **T1.3 的"低于 -20 抬一档"不适用**：它要达到的电平（-12~-6），产品实际场景
  （真实语音 vol80）下已经达到了，是 -9.0 dBFS。

### 真正的电平风险在别处

**vol100 时两个通道都在削顶边缘 4 dB 以内**（ch1 -3.9 / ch0 -2.5 dBFS）。这是这次
量电平顺带发现的，比"回采偏小"这个原假设更值得关注——削顶会直接破坏 AEC 的线性
假设。设备持久化音量是 40，日常不会撞上；但把音量推到 100 做实验时要知道这一点。

## T1.1/T1.2 的实现与验收

两路增益改为从 Kconfig 显式写入，**写在 `esp_codec_dev_open()` 之后**——因为
open() 内部会走 `_update_codec_setting()` 把句柄默认增益写给所有通道，写早了会被
覆盖（这正是 ch1 一直停在默认值的原因）：

- `CONFIG_AEC_MIC_PGA_GAIN_DB` 默认 30
- `CONFIG_AEC_REF_PGA_GAIN_DB` 默认 **0**，并把上面这套实测依据写进 Kconfig help，
  免得下一个人看到"0"又当成 bug 去抬。

### 验收方式：必须让它变一次

T1.1 的判据是"改配置后读寄存器能看到变化"。**保持原值不变的读数什么都证明不了**
——REG44 读出 0 dB，既可能是我的显式写入生效，也可能是我的代码根本没跑、读到的是
旧默认路径留下的同一个值。两者无法区分。

所以做了一次真正的对照：临时把默认值改成 6 dB 发一版（v44），读寄存器：

```
改前 (v43): REG43=0x1A (30.0dB)   REG44=0x10 (0.0dB)
改后 (v44): REG43=0x1A (30.0dB)   REG44=0x12 (6.0dB)   ← 跟着变了
```

REG44 跟着配置动、REG43 保持不动，证明**两路可独立配置且配置确实抵达寄存器**。
**T1.1/T1.2 验收通过。** 随后 v45 改回 0 dB。

这个"必须让它变一次"的模式在本次工作里反复出现，值得单独记一笔：E5 的误触发计数
三轮都是 0（看起来一切正常，实际藏着两层回归，靠独立校验才发现）；寄存器读数不变
（可能生效也可能没跑）。**单一指标"看起来正常"不等于系统正常。**

## 状态

- T1.1 拆出两个独立配置项：✅
- T1.2 打开后显式设置两路：✅（含"必须在 open() 之后"这个顺序要求）
- T1.3 回采电平校准：✅ **实测已在目标区间，无需调整**——这一项的结论是"不动"，
  不是"没做"。
- 建议加的"开机自检（播一小段信号检查 ch1 峰值是否合理）"：**未做**。现在有
  `es7210_regs` 可以随时读增益、有 `ref_level.py` 可以从任何一次采集算峰值，
  自检的价值下降了；真要做的话更应该盯"vol100 逼近削顶"这个已知风险点。

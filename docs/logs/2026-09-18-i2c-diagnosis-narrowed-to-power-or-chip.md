# 2026-09-18 · I²C 故障排查：总线健康，芯片彻底静默，缩小到供电或芯片本身

## 两步诊断，零硬件改动

**v102 — 线电平**:SDA(GPIO1)=1, SCL(GPIO2)=1,空闲态都是高。
排除总线短路、上拉失效、接地断裂。

**v103 — 全地址扫描**:`i2c_master_probe` 遍历 0x08–0x77 共 120 个 7 位地址,
**一个都没有 ACK**。排除"芯片换了地址"或"地址选择引脚接错"——
不是配置问题,是**芯片真的不在总线上**。

## 结论

```
总线电气健康 + 零应答 = 芯片没上电，或芯片本身坏了
```

两颗芯片(ES8311 @0x18, ES7210 @0x40)同时从总线消失,且断电重启不能恢复
(见前一篇记录),最可能的解释是它们**共用的供电轨**掉电或跳闸——
这样总线本身(无源器件)照常健康,但两颗芯片都无法响应。

## 下一步：接线测供电

加了 `adc_read` 命令,读 GPIO9(ADC1_CH8,板上确认空闲)的电压。
用户接一根线从疑似故障的 VDD 网络到 GPIO9,读数判读:

| 读数 | 指向 |
|---|---|
| ~0mV | 供电确实断了 |
| ~3300mV | 供电正常，问题在芯片本身 |
| 中间值 | 供电异常（跳闸残压等），仍是电源问题 |

**约束**:GPIO9 是 ADC 输入,接入电压不能超过 3.3V,接线前先确认额定电压。

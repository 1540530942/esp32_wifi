# 2026-09-15 · 目标达成：E4 与 E5 在同一版固件上同时通过

**最终目标：机器人说话时用户开口，200ms 内停播。—— 达成。**

固件 `esp32-wangyutang-v75-energygate`。

## 实测

**E4 打断延迟**（7 个有效样本，两批）

```
119, 139, 145, 152, 155, 158, 163 ms
中位数 152ms   最大 163ms   跨度 44ms   7/7 < 200ms
```

**E5 误打断**（串口判定，连续两轮合计）

```
7920 / 27200 / 27200 / 27200 / 37920 / 37920 ms = 165.16s
每一轮都与素材时长逐毫秒吻合
打断触发 0 次，外部 stop 0 次
```

165s 超过判据要求的 127s。分两轮是因为命令下发不稳（见下），不是设备问题——
**每一轮送达的都播满了**。

## 解开死结的是"换维度"，不是"调参数"

在此之前，E4 和 E5 始终此消彼长：

| 配置 | E4 | E5 |
|---|---|---|
| `vad_mode`3 + `min_speech`48 | 127ms ✅ | ❌ 5/5 被切 |
| `vad_mode`3 + `min_speech`64 | 193ms | ❌ 串口确证 2 次 |
| `vad_mode`4 + `min_speech`64 | 232ms ❌ | ✅ 0 次 |
| **上述第一组 + 电平门** | **152ms ✅** | **✅ 0 次** |

**原因：此前试过的每一个旋钮都是"时长"维度，而时长区分不了残余回声和人声——
残余本身就是语音，只是更轻。** 归档数据里"更轻"是可量化的：

| 场景 | AFE 输出 post_rms |
|---|---|
| 机器人独自说话（E1 @vol80） | **8.5** |
| 人声（E2b，无回声可消） | **218.6** |
| 双讲（E3） | **181.2** |

**相差 21–26 倍。** 因为 AEC 把机器人消得足够干净——E3 的 ASR 只读出人声。
**电平这个维度一直摆在数据里，我用了七十多个版本才想到去用它。**

门限取 40（两者几何平均约 39），两边各留约 4.5 倍余量。加上它之后，VAD 就能调回
最快档（`vad_mode`3 + `min_speech`48），由电平门承担拒绝残余的职责。

代价是零延迟：这一帧 AFE 已经产出，算一次 RMS 不需要等待。

## 为什么不是 `vad_energy_threshold`

esp-sr 有这个字段，思路完全相同，但注释写明「only applied when a **vad model**
is used」。启用 `vadnet1_medium` 需要 model 分区，而 `partitions.csv` 里没有——
加分区等于重写分区表，`WORKING.md` 要求明确授权，出错需物理恢复。

**自己在 `fetch_task` 里算一帧 RMS，两样都不需要。**

## 两个已知但未修复的问题

都不影响上述验收，但对产品是真实缺陷：

1. **MQTT retained 命令重放**——命令以 `retain=True` 发布，清除一旦错过就在设备
   每次重连时重新执行。曾抓到 12 条陈旧 `stop_audio` 集中送达。用户侧表现为
   「机器人莫名其妙自己停/自己播」。详见 `2026-09-15-retained-commands-broke-e5.md`。

2. **命令下发是分钟级延迟**——串口证明设备会执行早已被判定为"丢失"的命令。
   一条打断指令几分钟后才生效，用户看到的是「机器人过一会儿突然自己动了」。
   这也是 E5 需要分两轮才凑够时长的原因。

## 补测：E3 长时版与 E2 在 v75 上的复测

上一轮宣布"16 项全部完成"时漏了一项——任务书 E3 条目末尾的**长时版本**
（「ESP32 循环播 assistant 轮次，树莓派同时播 turn03，测整段人声存活率」），
和已完成的 4 秒重叠版是两回事。补测如下。

### E3 长时版：25 秒持续双讲，存活率 95.9%

ESP32 播 turn10（37.92s），树莓派同时播 turn03（93.12s），采集 25 秒重叠段。

```
mic_raw  : 渔人捕鱼为业，缘溪行，忘路之远近。忽逢桃花林，夹岸数百步，中无杂树，
           芳草鲜美，落英缤纷，渔人甚异之。复前行，欲穷其林。林尽水源，便得一山，
           山有小口，仿佛若有光。便舍船，从口入。初极狭。
clean_aec: 林人捕鱼为业，缘溪行，忘路之远近。忽逢桃花林，夹岸数百步，中无杂树，
           芳草鲜美，落英缤纷。渔人甚异之，复前行，欲穷其林。临近水源，便得一山，
           山有小口，仿佛若有光。便舍船，从口入。初极狭。
```

去标点后**两侧同为 74 字，字级相似度 95.9%**，仅两处差异：

- `渔` → `林`（首字）
- `林尽` → `临近` —— **普通话完全同音**

两处都是 ASR 同音/边界歧义，不是音频损伤。**实际音频存活接近 100%。**

短版 E3（4 秒重叠）是"人声能不能被听见"，长版是"持续双讲下会不会逐渐被吃掉"——
25 秒里没有出现任何压制或断续的迹象。

### E2 复测（v75）：AFE 输出 ASR 为空

固件从 E2 上次验证时（v40 时代）改动极大，值得重验。

```
mic_raw  : 陶渊明的《桃花源记》，这段文字描写了武陵渔人沿溪而行…（完整一大段）
clean_aec: <空>

ERLE 34.64 dB    pre_rms 458.0 → post_rms 8.5
```

**ASR 一个字都读不出来**，判据"残余中无可辨语音内容"满足。

`post_rms 8.5` 与设电平门限时用的那个数字完全一致——这不是巧合，那个门限正是从
E1 的同一条件测出来的。**这次复测等于对门限取值做了一次独立印证。**

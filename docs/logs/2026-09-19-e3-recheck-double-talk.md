# 2026-09-19 · E3 双讲复测（核心项）

ESP32 播 turn04（assistant），采集开始 10s 后树莓派插入 turn05（4.08s，
"对的，这是我喜欢的陶渊明诗人，你来背诵另外一首"）。`--mute-bargein`
保证打断只统计不执行，让双讲按设计持续下去，不被提前砍断。

## 结果

聚合 `erle_full_db=13.25dB`，比 E1/E2 的 40dB 级别低很多——**这是预期
之内的**，不是退步：双讲段里 turn05 的真实能量本就不该被消掉，混入
单讲段一起取平均，数字自然被拉低，不能直接套 E1 的判读表。

真正的判据（ASR 内容比对）：

| | 转写 |
|---|---|
| turn05 原始素材 | 对的，这是我喜欢的陶渊明诗人。你来背诵另外一首。 |

逐字吻合（仅标点差异）。整段 27s 输出转写出来的内容就是 turn05 的原话——
说明 turn04 的回声被压制到不构成可识别内容，而 turn05 的人声完整、
清晰地保留了下来。E3 通过，且是强通过（不是勉强达标）。
